# Retrieve current canonical authority
Use `governance/source-registry.json` as bootstrap pointers and retrieve the current Source Map.
If an owner is absent locally, resolve it from the live map; local omission does not make it
noncanonical. Verify current nonblank title, ID and status before use or factual pointer repair.

Retrieve task-relevant sections with actual supported tools, reusing fresh reads. Live Drive
authority wins over stale local pins. Do not invent version/date text when absent.
Reject RETIRED, LEGACY, SUPERSEDED, ARCHIVED and staging instructions for ordinary execution.
Explicit history audits can inspect them as evidence, without adopting their instructions.
Executed chronology remains relevant source evidence.

On failure hold only dependent claims/edits, continue independent work and retain the exact owner,
proposed delta and resume condition. Accepted durable decisions use AI Runbook Refresh and Change
Control; chat-only guidance is not a save. Do not force snapshot copies or turn a retired file into
a new canonical file. No canonical bodies or live client data in Git.

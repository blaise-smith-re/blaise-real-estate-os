# Task-local capability check
Read the invoking wrapper's `governance/required-connectors.json` entry and actual host tool
metadata. Compatibility prefixes do not establish another host's access. Use a bounded read when
material and reuse fresh healthy capability evidence.

Missing required access means HOLD immediately for dependent work only. Name the exact lane and
continue independent useful work. Do not blind-retry a known outage, present reported information
as retrieved, update a verification date for an unperformed read or change credentials.
Calendar is optional unless a particular recorded-event claim depends on it. No events does not
mean no commitments.

Workers retain their actual tool grants. A capable orchestrator uses its own authorized tools;
this skill does not expand worker grants. Installed configuration is not proof of source access
or a successful unattended run. Historical certification scopes do not impose new routine gates.
Report relevant gaps concisely and apply the AI Runbook source-system completion check.
